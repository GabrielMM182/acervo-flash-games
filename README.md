# flash-local

Personal archive of old Flash games, played locally through Ruffle, with optional cheat variants produced by byte-level patches. Everything here is for personal use only; do not redistribute the SWF files.

This file is the starting context for any future session: it explains how the archive is organized, how a new game is added, and how cheats were built, so the work can be reproduced without the original conversation.

## Layout

```
flash-local/
  index.html              Library page + Ruffle player (game/variant chosen by query string)
  server.mjs              Dependency-free static server, 127.0.0.1:8090 (PORT/HOST env override)
  quarantine/             Temporary download directory (should be empty between game additions)
  tools/
    inspect-swf.mjs       Static check: header, stage, AVM1 vs AVM2, tag counts, URLs, network keywords
    disasm-swf.mjs        AVM1 disassembler (DoAction + DefineButton2 only) for diffs
    avm1.mjs              AVM1 analysis/patch library used by cheat and fix patchers
  games/<game-id>/
    <game-id>.swf         Original file, never modified
    <game-id>-<variant>.swf  Variants generated by patchers
    source/               ActionScript exported by FFDec (read-only reference)
    cheats/               Cheat patchers
    fixes/                Compatibility patchers (e.g. sitelock)
```

External tool: JPEXS FFDec 26.3.0 (portable zip from GitHub `jindrapetrik/jpexs-decompiler`) extracted at `C:\Users\insti\tools\ffdec_26.3.0\`. Runs with any Java 8+ on PATH.

## Running

Nothing runs after a reboot. Every time you want to play:

```bash
node C:/Users/insti/flash-local/server.mjs
```

Keep that terminal open, then open `http://localhost:8090/` for the library, or `http://localhost:8090/?game=<id>&variant=<variant>` directly. Without `variant`, the first variant listed for the game in `index.html` is used. Stop with `Ctrl+C`. Port 8080 is reserved for other projects, so the archive uses 8090.

The page downloads Ruffle from unpkg, so an internet connection is needed unless the browser has it cached. The games themselves are local.

To use the Claude desktop browser pane instead, add this entry to `C:\Users\insti\.claude\launch.json` and call `preview_start` with name `flash-local` (remove it afterwards to keep work configuration clean). If the server is already running in a terminal, just navigate the pane to `http://localhost:8090`.

```json
{
  "name": "flash-local",
  "runtimeExecutable": "node",
  "runtimeArgs": ["C:/Users/insti/flash-local/server.mjs"],
  "port": 8090
}
```

## Library interface

The main page (`http://localhost:8090/`) displays a modern grid-based library inspired by emulator frontends like RetroArch and Launchbox. Each game is shown as a card with:

- **Cover image**: Automatically loaded from Flashpoint Archive via `flashpointId` (screenshots or logos)
- **Title**: Game name
- **Metadata**: Developer, year, and genre
- **Variant badges**: Clickable pills for each available version (original, cheats, unlocked)

The interface is fully responsive and uses a dark theme optimized for browsing. Click any variant badge to launch the game in fullscreen mode with Ruffle. A "Back to Library" button returns you to the game grid.

**Cover images**: Fetched on-demand from `https://infinity.unstable.life/Infinity/images/Screenshots/{flashpointId}.png`. If unavailable, a 🎮 placeholder is shown. No manual image management needed.

## Network isolation

Two layers, both in `index.html`:

1. **Content-Security-Policy meta tag** (the one that actually enforces isolation): `connect-src 'self' https://unpkg.com`, `frame-src 'none'`, `object-src 'none'`, `form-action 'none'`. The browser refuses any connection to another host before the request leaves the machine. Verified by a `securitypolicyviolation` event on a test fetch.
2. **Ruffle config**: `allowNetworking: "none"`, `openUrlMode: "deny"`, `allowScriptAccess: false`. Important: in Ruffle 0.6.0 `allowNetworking` does **not** stop AVM1 `loadMovie` (The Last Stand 2 and Union City tried to fetch CPMStar ads before the CSP existed; no user data was sent). Never rely on the Ruffle option alone.

Ruffle is loaded from `https://unpkg.com/@ruffle-rs/ruffle@0.6.0/ruffle.js` (pinned; versions younger than two weeks were avoided). SharedObject saves live in the browser's localStorage for `localhost:8090`; clearing site data erases saves.

## Why this is safe

A SWF is not a Windows executable. Historical Flash malware exploited memory-corruption bugs in Adobe Flash Player itself. Ruffle is a separate implementation written in Rust, compiled to WebAssembly, and runs inside the browser sandbox with no file-system access. The remaining risk is the game reaching the network (old ad/score servers whose domains may now belong to someone else), which the CSP blocks. Never run the SWF with Flashpoint's bundled `flashplayer_32_sa.exe` (old Adobe projector).

## Download sources

**Flashpoint data packs** (preferred):
- URL pattern: `https://download.unstable.life/gib-roms/Games/<id>-<timestamp>.zip`
- Contains multiple versions (Armor Games, Kongregate, Newgrounds, etc.) in one package
- May be unavailable or return 404 for some games
- Service availability can be intermittent

**Internet Archive** (fallback):
- URL: `https://archive.org` (search by game title or SWF filename)
- Trusted non-profit digital library, safe source
- Games preserved by individual uploaders, so availability varies
- Direct SWF downloads (no ZIP extraction needed)

Both sources are safe. The quarantine folder and static check provide an additional validation layer before integrating games into the archive.

## Adding a new game

1. **Locate it on Flashpoint Archive.**
   - Site search: `https://flashpointarchive.org/search`.
   - Database API (works with curl):
     `https://db-api.unstable.life/search?title=<words>&platform=Flash&fields=id,title,developer,publisher,releaseDate,tags,originalDescription,launchCommand&limit=200`
     Use `id=<id>` to read one entry, or `originalDescription=<word>` to search by what the game was about, then filter locally.
   - Portuguese portals such as Click Jogos often renamed games; search by mechanics/description, not by the remembered Portuguese title.
   - Entry page: `https://flashpointarchive.org/view?id=<id>` shows status, launch command (SWF name), size and screenshot.
2. **Find the download source (priority order):**
   - **First, try Flashpoint data pack:** The 9o3o page `https://ooooooooo.ooo/?id=<id>` may contain the URL `https://download.unstable.life/gib-roms/Games/<id>-<timestamp>.zip`. Use `curl -sI` to check availability and read size before downloading. This is the preferred source as it often includes multiple versions (Armor Games, Kongregate, Newgrounds) in one package.
   - **If Flashpoint pack is unavailable, try Archive.org:** Search for the game title or SWF filename at `https://archive.org`. The Internet Archive is a trusted non-profit digital library and a safe alternative source. Many Flash games have been preserved there by individual uploaders.
   - **Last resort:** Check if the original host URL (from launch command) still works, but be aware most historical game portals are offline.
3. **Download into quarantine folder**:
   - **For ZIP packs:** Download to `quarantine/`, run `unzip -l` and check that no entry contains `..` or an absolute path, then extract.
     - Packs often hold several copies of the game (Armor Games, Kongregate, Newgrounds, foreign portals, "prehacked" versions from arcadeprehacks). Use the file matching the entry's launch command (normally the original publisher's). Do not use third-party prehacked files; cheats are made here, documented and reversible.
   - **For direct SWF files:** Download to `quarantine/<game-name>.swf` and proceed to static check.
4. **Static check** (run from a different directory than the download):
   ```bash
   node C:/Users/insti/flash-local/tools/inspect-swf.mjs "<path-to-swf>"
   ```
   Look at: signature (`FWS`/`CWS` fine, `ZWS` = LZMA not supported by the tools), SWF version, `avm` (AVM1 = AS1/AS2, AVM2 = AS3; the header version alone does not tell, e.g. Weapon is v9 but AS2), `urlLikeStrings` and `keywordHits` (`loadMovie` usually means ads; `services.armorgames.com`, Kongregate, Newgrounds mean portal APIs). Expected noise: publisher/developer links, `_blank`, `SharedObject`, XMP metadata URLs, font credits.
5. **Copy** the SWF to `games/<id>/<id>.swf` and register it in the `GAMES` object in `index.html` (title, stage width/height from the check, variants; the first variant is the default).
   - Open `index.html` and locate the `GAMES` object in the `<script>` section
   - Add a new entry following this template:
   ```javascript
   "<game-id>": {
     title: "Game Title",
     developer: "Developer / Publisher",
     year: "YYYY",
     genre: "Genre Category",
     flashpointId: "<flashpoint-uuid>",  // From the entry page URL
     width: 800,   // From inspect-swf.mjs output
     height: 600,  // From inspect-swf.mjs output
     variants: {
       original: "games/<game-id>/<game-id>.swf",
     },
   },
   ```
   - The `flashpointId` enables automatic cover images from Flashpoint Archive
   - Screenshots load from: `https://infinity.unstable.life/Infinity/images/Screenshots/{flashpointId}.png`
   - If the image doesn't exist, a placeholder 🎮 is shown automatically
6. **Export the scripts** for reading:
   ```bash
   java -jar C:/Users/insti/tools/ffdec_26.3.0/ffdec-cli.jar -format script:as -export script C:/Users/insti/flash-local/games/<id>/source C:/Users/insti/flash-local/games/<id>/<id>.swf
   ```
7. **Test** in the browser: page loads, Ruffle console has no errors, the game's own preloader reaches 100%, the menu appears. Large games can take 30-60 s in the preloader under Ruffle; some intros stop and wait for a click on a specific button.
8. **Clean quarantine** after successful installation: `rm quarantine/*` (the directory should be empty between game additions).
9. **Update this README** (archive table, hashes, notes).

### Sitelocks

Many portal games check where they were loaded from. Typical AS2 pattern: take `_url`, extract the last two labels of the host, and show an "exclusive to ..." screen when the domain is not the portal's. Running from `http://localhost:8090` fails that check. Ruffle 0.6.0 has no URL spoofing option, so the fix is a compatibility patcher in `games/<id>/fixes/` that produces an `unlocked` variant (listed first so it is the default) and keeps the original:

- Grep the exported source for `_url`, `domain`, `exclusive`; read the condition.
- In the bytecode the guard ends with `Push "<domain>", Equals2, Not, Not, If +N` (the `&&` short-circuit lands on the second `Not`), followed by the lock block.
- Swap the final `Not, If` to `Pop, Jump` (same offset): both paths discard the condition and always skip the lock block. 2 bytes.
- `games/last-stand-2/fixes/patch-sitelock.mjs` is the template (uses `findSequences` from `tools/avm1.mjs`).

## Building cheats

### Rules learned the hard way

- **Never save modified scripts through FFDec** (neither ActionScript recompile nor P-code `-replace`). On Flash MX era SWFs it silently removed the register save/restore that the compiler emits around every `DefineFunction` (v1) body (`Push r1, r2, r3` at entry, `StoreRegister`/`Pop` at exit). Functions in SWF6 share four global registers, so removing that can corrupt variables between nested calls. Use FFDec only to read/export.
- **Patch bytes in place with same-length swaps.** Nothing moves, so no jump offsets, function sizes or tag lengths need to be recalculated.
- **Always assert the expected number of sites**, counted independently by grepping the exported ActionScript, and re-scan the patched file to confirm zero sites remain.
- **Never modify `<id>.swf`.** Every change goes to a new `<id>-<variant>.swf`.

### Workflow

1. Grep the exported `source/` for the variable (`health`, `lives`, `ammo`, `money`, `credits`, `barricade`, ...). Find where it is initialized, where it decreases, and where the game-over check is.
2. Count the decreasing sites in the source, e.g. `grep -rhoE '_root\.health -= ' source | wc -l`. That number becomes the patcher's expected count.
3. Write `games/<id>/cheats/patch-<id>.mjs` on top of `tools/avm1.mjs` (the Weapon patcher is the template): find sites, assert counts, apply swaps per variant, re-scan, report changed bytes, save `games/<id>/<id>-<variant>.swf`.
4. Register the variants in `index.html`, test in the browser, update this README.

### Useful same-length swaps (AVM1)

| Goal | Original opcodes | Replacement | Bytes |
|---|---|---|---|
| Never enter a branch guarded by `a < b` | `Less2, Not, If` | `Pop, Pop, Jump` (same offset) | `48 12 9D` -> `17 17 99` |
| Never enter a branch guarded by an already-computed condition | `Not, If` | `Pop, Jump` (same offset) | `12 9D` -> `17 99` |
| Cancel `obj.x -= expr` | `Subtract` before `SetMember` | `Pop` (discard expr, write old value back) | `0B` -> `17` |
| Cancel `x--` style decrement (not used yet) | `Decrement` | `ToNumber` | `51` -> `4A` |
| Change a starting value | `Push` number literal | Same literal type with a new value | in place |

Stack reasoning for `Subtract -> Pop`: before it the stack holds `[object, "name", current, damage]`; `Pop` drops `damage`, `SetMember` stores `current` back, so the value never changes.

### `tools/avm1.mjs`

- `loadSwf(path)` / `saveSwf(path, swf)`: inflate/deflate `CWS` (zlib) or plain `FWS`; header keeps version and uncompressed length.
- `listActionBlocks(swf)`: every AVM1 action block, recursing into sprites: `DoAction`, `DoInitAction`, `DefineButton2` conditions, `PlaceObject2` clip events (matrix and color transform bit fields are skipped to reach them). `PlaceObject3` clip events and `DefineButton` (v1) are reported as skipped.
- `listInstructions(body, block)` / `findSequences(swf, matcher)`: decoded instructions with byte offsets and resolved `Push` values; `findSequences` runs a matcher at every instruction of every block (used for opcode patterns such as the sitelock).
- `simulateBlock(body, block, onStore)`: symbolic stack simulation (no execution). Every `SetMember`/`SetVariable` is reported with its target and a tree describing the stored value (literals, variables, `_root.x` reads, operations with their byte offsets). `DefineFunction2` preloaded registers (`this`, `_root`, `_parent`, `_global`, named parameters) are resolved, which matters for AS2 code where `_root` lives in a register. Straight-line only: the stack is reset after `If`, `Jump` and function definitions.
- Helpers: `isRootMember(node, name)`, `writeNumberLiteral(body, literal, value)`, `countChangedBytes(a, b)`, `OP` opcode table.
- Not supported: AS3 (`DoABC`) games, LZMA (`ZWS`) files. AS3 cheats would need an ABC bytecode parser instead.
